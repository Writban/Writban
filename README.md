MSc Computing Science graduate focused on **cybersecurity, applied AI, and practical software**. I build security tools, interactive AI, useful web apps, and the occasional skeleton.

## Flagship projects

### [Attack Tree Assistant — MSc Dissertation](https://github.com/Writban/Attack-Tree-Assistant-MSc-dissertation)
Interactive attack-tree editor with knowledge-base suggestions, review/pruning support, fuzzy and semantic matching, and plain-English explanations for non-expert users. Evaluated in a within-subject study with **20 novice participants**; the suggestion module produced a significant increase in the study's tree-size coverage measure (**p = 0.016, r = 0.68**), while the pruning results exposed clear limitations that are documented in the repository.

**Live app:** https://writban.github.io/Attack-Tree-Assistant-MSc-dissertation/

### [Neural Network Visual Lab](https://github.com/Writban/Neural-Network-Visual-Lab)
Interactive TypeScript/React lab that implements small neural networks directly in the browser, including seeded datasets, editable architectures, forward propagation, backpropagation, decision boundaries, experiment comparison, and a guided course.

**Live lab:** https://writban.github.io/Neural-Network-Visual-Lab/

### [SiteGraph](https://github.com/Writban/SiteGraph)
Browser-based website-structure analyser that turns local HTML projects into an interactive navigation graph and detects broken links, orphan pages, dead ends, unreachable pages, and excessive click depth. Analysis stays local in the browser.

**Live analyser:** https://writban.github.io/SiteGraph/
