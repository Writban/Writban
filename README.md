# Hi, I'm Writban Alim

MSc Computing Science graduate interested in **cybersecurity, applied AI, and interactive software**. I like building tools that make technical systems easier to inspect, understand, or experiment with.

## Featured projects

### [Attack Tree Assistant — MSc Dissertation](https://github.com/Writban/Attack-Tree-Assistant-MSc-dissertation)
Interactive attack-tree editor developed for my MSc dissertation, with knowledge-base suggestions, pruning support, semantic matching, and plain-English explanations for non-expert users.

### [Neural Network Visual Lab](https://github.com/Writban/Neural-Network-Visual-Lab)
Interactive TypeScript/React lab that implements and visualises small neural networks directly in the browser, including seeded experiments, editable network structure, backpropagation, decision boundaries, and a guided course.

**Live demo:** https://writban.github.io/Neural-Network-Visual-Lab/

### [SiteGraph](https://github.com/Writban/SiteGraph)
Browser-based website-structure analyser that converts local HTML projects into an interactive navigation graph and detects broken links, orphan pages, dead ends, unreachable pages, and excessive click depth.

### [RPS Colosseum](https://github.com/Writban/Rock-Paper-Scissors-Colosseum)
Adaptive Rock-Paper-Scissors experiment with behavioural prediction, an additional commitment layer, and SHA-256 commit-reveal verification so the opponent's choices can be audited after play.

### [Skeleton Wars](https://github.com/Writban/Skeleton-Wars)
A small Godot action-platformer project used to explore game-state design, movement, collision, resources, revival mechanics, and character behaviour.
